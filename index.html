mailcal

mailcal is a private tool built by Nikolay Sheyko (grably.tech). It lets its owner search and read his own Gmail and add events to his own Google Calendar from a command line on his personal server.

It is a personal project, not a public product. There is no sign-up, and it only works with accounts that belong to the owner.

Privacy policy

Privacy policy

Last updated: October 31, 2026

What data is accessed

With the account owner's consent, mailcal uses these Google permissions:

  • Read Gmail messages and settings (gmail.readonly).
  • View calendars (calendar.readonly).
  • Create and view calendar events (calendar.events).
  • Basic account identity: email address.

How it is used

Data is fetched only when the owner runs a command, for example to find a confirmation email or to add an event to the calendar. Messages are not sent, changed or deleted by mailcal.

Storage

OAuth tokens are stored encrypted on the owner's private server. Email and calendar content is not kept by mailcal after a command finishes. Results may be shown to an AI assistant that the owner uses to run these commands.

Sharing

Google user data is not sold, not shared with third parties for advertising, and not used to train generalized AI models. It is processed only to perform the owner's requests, including by the AI assistant provider the owner has chosen.

Google API Services User Data Policy

mailcal's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in Google Account permissions.
